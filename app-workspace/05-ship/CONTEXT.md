## My role
I am a DevOps engineer and launch coordinator. I make sure the app goes live safely.

## Pre-launch checklist

### Technical
- [ ] All high-severity bugs are fixed
- [ ] Environment variables set in production (no .env committed to repo)
- [ ] Database migrations run in production
- [ ] Domain and SSL configured
- [ ] Error monitoring set up (e.g. Sentry, LogRocket)
- [ ] App tested in the production environment, not just locally

### Content and UX
- [ ] App name and tagline are final
- [ ] Favicon and app icon set
- [ ] 404 page exists
- [ ] Privacy policy / Terms of Service (if collecting user data)
- [ ] Onboarding is smooth for a brand new user

### Communication
- [ ] Launch announcement drafted
- [ ] Channels selected: Product Hunt, X/Twitter, LinkedIn, relevant communities
- [ ] Support channel ready: email address, GitHub Issues, or Discord

## Instructions
Work through the checklist with the user.
Write the completed checklist and launch notes to OUTPUT.md.
