# Skill: Write a Feature Spec
> Load this when adding a new feature task to 03-build/TASK-LIST.md.

Before writing any code, write a spec in this format:

## Feature: [name]

**User story:**
As a [specific user type], I want to [action] so that [outcome].

**Acceptance criteria:**
- [ ] [Condition 1 — observable, testable]
- [ ] [Condition 2]
- [ ] [Condition 3]

**Data:**
What is created, read, updated, or deleted?

**UI:**
What does the user see? What do they interact with?

**Edge cases:**
What can go wrong? How does the app handle each case?

**Out of scope:**
What is explicitly NOT part of this feature?
